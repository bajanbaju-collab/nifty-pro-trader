Server setup required
  1. Create a Kite Connect app for this terminal.
  2. Set its registered redirect URL to https://nifty-pro-trader.onrender.com/api/kite/callback.
  3. In Render service → Environment, set KITE_API_KEY and KITE_API_SECRET. Redeploy the service.
  4. Return here and select Connect Kite. Zerodha login happens on Zerodha’s site.

Never enter or send API secrets in this page or chat. An in-memory read-only session may disappear when Render Free sleeps or restarts. Kite tokens expire and require a new login.
